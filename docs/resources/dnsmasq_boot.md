# opnsense_dnsmasq_boot (Resource)

Configure DHCP boot information for dnsmasq.

## Example Usage

```terraform
// PXE lan
resource "opnsense_dnsmasq_boot" "pxe_lan" {
  interface = "lan"
  file_name = "pxelinux.0"
}

// PXE Boot
resource "opnsense_dnsmasq_boot" "pxe_install" {
  interface = "lan"

  tag = [
    "pxe",
    "install"
  ]

  file_name      = "ipxe/boot.ipxe"
  server_name    = "pxe-server"
  server_address = "192.168.110.10"

  description = "PXE boot for installation clients"
}

// PXE Provisioning
resource "opnsense_dnsmasq_boot" "provisioning" {
  interface = "kubernetes"

  tag = [
    "provisioning"
  ]

  file_name      = "ipxe/k8s.ipxe"
  server_address = "192.168.111.10"

  description = "iPXE boot for Kubernetes provisioning"
}

// PXE Boot Server
resource "opnsense_dnsmasq_boot" "pxe_server" {
  interface    = "lan"
  file_name    = "pxelinux.0"
  server_name  = "pxe.example.internal"
  description  = "PXE boot from internal boot server"
}
```

## Schema

### Required

- `file_name` (String) The filename to send for the client.
- `interface` (String) This adds a single interface as tag so this DHCP boot option can match the interface of a DHCP range.

### Optional

- `description` (String) You may enter a description here for your reference (not parsed).
- `server_address` (String) The sever address to send for the client.
- `server_name` (String) The server name to send for the client.
- `tag` (Set of String) If the optional tags are given then this option is only sent when all the tags are matched. Can be optionally combined with an interface tag.

### Read-Only

- `id` (String) UUID of the boot object.
