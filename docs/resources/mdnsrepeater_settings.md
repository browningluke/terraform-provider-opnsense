# opnsense_mdnsrepeater_settings (Resource)

Manages mDNS Repeater settings. Requires the `os-mdns-repeater` plugin. This is a singleton resource that manages existing upstream configuration.

**Important:** This resource must be imported before it can be managed:
```bash
terraform import opnsense_mdnsrepeater_settings.settings mdnsrepeater_settings
```

After importing, you can manage the configuration with `terraform apply`. Running `terraform destroy` will remove the resource from state but will NOT modify the upstream configuration.

## Example Usage

```terraform
# This is a singleton resource. It must be imported before use:
# terraform import opnsense_mdnsrepeater_settings.settings mdnsrepeater_settings

resource "opnsense_mdnsrepeater_settings" "settings" {
  enabled    = true
  interfaces = ["lan", "opt1"]
  blocklist  = ["192.168.1.0/24"]
}
```

## Schema

### Required

- `interfaces` (Set of String) Listen interfaces (e.g. `lan`, `opt1`). At least 2 interfaces must be set when `enabled` is `true`. The daemon supports at most 5 interfaces.

### Optional

- `blocklist` (Set of String) Up to 16 client IPv4 addresses or networks, in CIDR notation, to exclude. Defaults to `[]`.
- `enable_carp` (Boolean) When enabled, the repeater service only runs on the CARP master. Defaults to `false`.
- `enabled` (Boolean) Whether to enable the repeater. Defaults to `false`.

### Read-Only

- `id` (String) Always set to `mdnsrepeater_settings`. Use this value when importing.
