# opnsense_interfaces_bridge (Resource)

Bridges connect two or more network interfaces into a single layer 2 segment.

## Example Usage

```terraform
// Bridge two assigned interfaces, letting OPNsense generate the device name
resource "opnsense_interfaces_bridge" "bridge" {
  description = "Example bridge"
  members     = ["opt1", "opt2"]
}

// Bridge with spanning tree enabled
resource "opnsense_interfaces_bridge" "bridge_stp" {
  description    = "Example bridge with STP"
  members        = ["opt3", "opt4"]
  enable_stp     = true
  stp_proto      = "rstp"
  stp_interfaces = ["opt3", "opt4"]
}
```

## Schema

### Required

- `members` (Set of String) Assigned interfaces to add as members of the bridge, e.g. `["opt1", "opt2"]`. At least one member is required.

### Optional

- `address_timeout` (Number) Timeout (in seconds) of bridge address cache entries. `0` disables expiry.
- `auto_edge_ports` (Set of String) Interfaces to automatically detect edge status on. Defaults to `[]`.
- `auto_ptp_ports` (Set of String) Interfaces to automatically detect point-to-point status on. Defaults to `[]`.
- `description` (String) Optional description here for your reference (not parsed).
- `device` (String) Custom bridge name, e.g. `bridge0`. Set to `""` to generate a device name. Defaults to `""`.
- `edge_ports` (Set of String) Interfaces to set as edge ports (always connected to an end of a LAN, never to another bridge). Defaults to `[]`.
- `enable_stp` (Boolean) Enable spanning tree options for this bridge. Defaults to `false`.
- `forward_delay` (Number) Time (in seconds) that must pass before an interface begins forwarding packets when spanning tree is enabled. Must be between `4` and `30`.
- `hold_count` (Number) Number of packets transmitted before being rate limited when spanning tree is enabled. Must be between `1` and `10`.
- `link_local` (Boolean) Enable link-local (IPv6) addresses on the bridge and its members. Defaults to `false`.
- `max_addresses` (Number) Maximum size of the bridge address cache. Must be at least `1`.
- `max_age` (Number) Time (in seconds) that a spanning tree configuration is valid. Must be between `6` and `40`.
- `private_ports` (Set of String) Interfaces to mark as private (do not forward traffic to other private ports). Defaults to `[]`.
- `ptp_ports` (Set of String) Interfaces to set as point-to-point links. Defaults to `[]`.
- `span_interface` (String) Interface to transmit a copy of every frame received by the bridge on. Set to `""` for none. Defaults to `""`.
- `static_ports` (Set of String) Interfaces to mark as static (no address learning). Defaults to `[]`.
- `stp_interfaces` (Set of String) Interfaces to enable spanning tree on. Defaults to `[]`.
- `stp_proto` (String) Spanning tree protocol to use. Available values: `rstp`, `stp`. Defaults to `rstp`.

### Read-Only

- `id` (String) UUID of the bridge.
